# 版本存檔

每次發布都會把當時的 `index.html`、`admin.html`、`setup.sql` 複製一份到這裡，資料夾名稱是「版本編號_發布日期」。
最新的版本就是目前網站上的版本。

這裡的檔案只是存檔，不能直接開來上課（資料夾裡沒有 `config.js`，打開會顯示找不到設定）。
要換回某一版時，跟 Claude 說「還原到 v10」之類的就可以；Claude 會把那一版的檔案放回根目錄，再照平常的流程發布。

注意：還原只會換回網頁，不會改資料庫。v03 以後才有 `setup.sql`；如果要還原的版本比某次資料庫變更還早，舊網頁可能用不到新功能，但學生資料不會受影響。
